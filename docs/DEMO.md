# Real-photo demo

[Watch the 1080p video](https://youtu.be/D4xqli_3MPo). Duration: 2 minutes 13 seconds, 1920 x 1080, 30 fps. Narration uses previously unlocked Suno Speech exports. No additional audio purchase was made.

It shows one real field photograph processed by OpenCV 5 on Lambda, its provisional review request and the matching S3/DynamoDB records. A second real photograph is an insufficient-edge case. The dated history view is a separate original synthetic example with illustrative dates. The opening school scenario is hypothetical AI concept art; the real photograph depicts a house.

The video displays the actual private AWS origin, server-reported OpenCV/Lambda runtime and AWS CloudShell evidence. The preview credential is supplied only in the judges-and-organizers testing field, never in this repository or the video.
