Technical details: OpenCV 5 and AWS

OpenCV fits operator-marked pole and reference edges, checks stable background correspondence and compares apparent image alignment. Other tools screen conductor continuity and nearby vegetation-colored regions. AWS Lambda runs the analysis, private S3 stores the images and DynamoDB keeps observations, comparisons and review requests.

Repeatable capture and marked references are required for the history comparison. This prototype does not diagnose cracks, measure physical pole lean, predict a fall date or calculate fire probability.
